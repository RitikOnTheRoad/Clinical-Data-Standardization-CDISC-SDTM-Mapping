📂 Repository Structure
dataset/: Contains the raw dataset(s) required for this project. (Note: To ensure the code runs correctly, do not alter the file names or structure within this directory).

script/: Contains all the source code and executable scripts needed to process the data, perform the analysis, and reproduce the results.

specs/: Contains the annotated Case Report Forms (aCRF) which serve as the mapping specifications for the Concomitant Medications (CM) and Vital Signs (VS) domains.

🚀 How to Run the Project
Clone this repository to your local machine.

Verify that the raw data files are present in the dataset/ folder.

Open and run the files located in the script/ folder to execute the data pipeline and generate the final outputs.
